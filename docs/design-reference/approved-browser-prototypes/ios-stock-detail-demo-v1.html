这一页的关键边界

把“想看什么”和“系统究竟知道什么”分开，避免精致但虚假的确定感。

预测趋势线必须是概率带同时展示中位路径、50% / 80% 区间、历史校准误差和失效条件，不画一条假装确定的未来价格线。
机构 / 散户占比只能标注口径美股实时成交通常无法直接知道账户身份。盘中只能给“机构流代理 / 散户流代理”；13F 等正式持仓数据必须明确披露滞后。
技术提示不直接等于买卖九转、K 线形态、RSI、MACD 都是特征和解释项，需要与事件、资金、市场状态共同确认。
13 位顾问按需调用默认只激活与当前周期和矛盾点相关的顾问；用户可以手动选择其他顾问。顾问只读证据包，其意见有权重上限。
多空共用同一事实层做空不会反向篡改新闻或算法结论；系统另加借券、费用、逼空、停牌和无限损失检查。
风险偏好不等于迎合稳健 / 均衡 / 进取只改变仓位、入场条件和允许的波动范围，不能提高预测置信度或删除反证。
仍然不接入交易权限。“复制到 moomoo”只复制建议参数或打开券商页面，用户必须自行核对并下单。
