首页组件清单

首页只放“现在最需要知道的事”。行情细节、K 线、财报、证据全文和建议单进入二级页面。

01
周期切换器三套模型完全隔离，默认展示短线。
02
市场结论与今日打法情绪结论、自然语言判断、总风险建议及关键因子。
03
高优先级提醒只显示最新且达到门槛的事件，附证据数与反证数。
04
moomoo Watchlist 脉搏价格变化、综合方向、分歧或风险状态。
05
潜力候选发现全市场扫描结果，先进入观察池，再经证据门控升级。
06
全局搜索与通知中心快速查股票、新闻事件、证据、历史分析和预警。
