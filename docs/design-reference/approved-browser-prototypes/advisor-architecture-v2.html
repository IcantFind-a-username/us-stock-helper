Revised Architecture · v2

市场情绪进入基础算法，个性化永不污染事实

新闻不只是推送列表，而要经过事件识别、来源权重、情绪聚合和市场联动分析。 系统可以给出数量、限价和杠杆等可解释建议，但技术上不具备下单能力。

不可覆盖的“客观性宪法” 事实与可靠来源优先于用户观点；反证必须展示；不确定就降级或弃权；用户偏好只能改变展示、提醒和风险场景，不能改变事实、方向判断或置信度。
01

信息与情绪感知

  • 正式消息、新闻、宏观、行业与市场微观结构
  • 社媒作为低权重线索，过滤机器人与重复传播
  • 区分事件情绪、个股情绪、行业情绪、全市场风险偏好
→
02

三周期基础评分

  • 情绪与新闻冲击正式纳入确定性特征
  • 与资金、技术、财务、估值和事件特征融合
  • 短线、波段、中长期分别训练与回测，不混权重
→
03

证据门控顾问

  • 阅读紧凑证据包，提出反证与补查请求
  • 作为有上限软因子，不能越过基础算法门槛
  • 输出引用、适用周期、失效条件和弃权状态
→
04

iOS 分析与建议

  • 显示结论、市场情绪、证据链与冲突
  • 提供仓位、限价、止损、目标和杠杆场景
  • 无交易 API、无下单权限、无自动执行

Hermes 式记忆，但加投资防火墙

长期积累经验，所有影响生产评分的变化均可见、可回滚。

市场经验库 · 可影响候选模型 保存 point-in-time 事件、当时可见证据、模型预测、后续反应和市场状态；只从市场事实与已验证结果中学习。
用户日志库 · 与市场判断隔离 记录用户主动填报的操作、盈亏、执行偏差和界面偏好；用于交易复盘、风险提醒与展示，不作为涨跌证据。
禁止通道 用户喜欢某股票、过去赚过钱、偏好多头或忽略风险，均不得提高股票评分、新闻可信度或模型置信度。
经验候选→ 离线回测→ 样本外验证→ 人工晋级

客观性与安全对话口：底层强制规则

事实 / 推断分栏每句话标记为事实、推断、情景或传闻，并绑定引用。
反迎合检查结论发布前主动寻找最强反证，不因用户表态改写方向。
双输出通道先给客观市场判断，再给基于风险预算的个性化场景。
冻结记忆快照每次分析绑定记忆、证据、模型和提示词版本，支持复现与缓存。
可撤销学习自适应更新走 champion / challenger；失效可归零和回滚。
